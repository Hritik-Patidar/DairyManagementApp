# Dairy Management System

A complete Dairy Management Application developed using Python and PyQt5 for managing milk collection, farmer accounts, transactions, products, balances, reports, and billing operations. The system is designed to simplify daily dairy operations and maintain accurate records in a centralized SQLite database.

## Features

### Farmer Management
- Create and manage farmer accounts
- Unique account number for each farmer
- View account details and transaction history
- Track farmer balances

### Milk Collection
- Daily milk collection entry
- FAT and SNF based milk rate calculation
- Automatic amount calculation
- Morning and evening session support

### Product Management
- Add, edit, and delete products
- Manage product prices
- Product purchase tracking

### Transaction Management
- Credit and debit entries
- Cash payments
- Product deductions
- Account settlement tracking
- Complete transaction history

### Billing System
- Generate bills instantly
- Thermal receipt printing support
- Printable reports
- WhatsApp bill sharing support

### Reports
- Daily collection reports
- Farmer-wise reports
- Transaction reports
- Payment reports
- Collection summaries

### Dashboard
- Latest bill history
- Quick access to common operations
- Account balance overview
- Recent transactions display

### Database
- SQLite database integration
- Secure local data storage
- Fast record retrieval
- Easy backup and restoration

## Technologies Used

- Python 3
- PyQt5
- SQLite3
- Pandas
- OpenPyXL
- FPDF
- PyWin32
- ReportLab
